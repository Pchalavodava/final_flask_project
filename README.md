Мой финальный Flask-проект

Возможности:
- регистрация и авторизация пользователя,
- просмотр как полного каталога книг, так и отдельно по жанрам,
- поиск по названию, автору, жанру и описанию,
- просмотр книги отдельно,
- добавление книги в корзину,
- оформление заказа/отмена не заплаченного заказа
- просмотр истории заказов,
- возможность оставить отзыв на закупленную книгу,
- автоматическое обновления, топ-3 проданных за последнюю неделю книг, каждый понедельник
- выход из аккаунта

Запуск приложения:
- запустить run.py
- с помощью модуля download_db.py загрузить базу данных
- приложение будет доступно по адресу http://127.0.0.1:5000
